# SpeedyCRM

SpeedyCRM — SaaS CRM для спортивных клубов на FastAPI, Aiogram 3, PostgreSQL, Redis и Docker.

Проект поддерживает:

- личный кабинет родителя и нескольких атлетов;
- авторизацию по номеру телефона;
- QR/FaceID сценарии прохода;
- абонементы, заморозку, оплаты и списания;
- админ-панель и суперадминскую обработку клубов;
- вебхуки, Docker Compose, Nginx, CI/CD и тесты.

## Что я изменил в этой ветке

Ниже перечислены именно мои последние правки, чтобы ты быстро понял, что было добавлено.

### Камеры и WebApp

- Добавил переключение между 4 камерами в `templates/cameras.html`.

- В профиле атлета добавлен блок с:

  - последними 5 посещениями.

### Дубли и чистка кода

- Убрал дубль функции `get_scanner_keyboard()` в `handlers/buttons.py`.
- Привёл тесты камеры в рабочее состояние после изменения сигнатуры стрима.

## Краткая структура проекта

- `main.py` — точка входа приложения.
- `admin_module/api.py` — FastAPI-роуты, WebApp, аналитика, стрим камеры.
- `handlers/` — Telegram-хендлеры, меню, авторизация, платежи, админка.
- `services/` — бизнес-логика проходов, аналитики и СКУД.
- `database/db.py` — модели SQLAlchemy и базовые функции работы с БД.
- `templates/` — HTML-шаблоны WebApp.
- `tests/` — pytest-тесты.

## Что важно знать по логике системы

- `Student.last_visit` всё ещё используется как маркер активной сессии.
- `visit_logs` — это отдельная история посещений, а не замена `last_visit`.
- Профиль показывает текущий статус и статистику, а история посещений нужна для аудита и детализации.

## Проверка

Локально тесты проходят:

```bash
python -m pytest -q
```

## Запуск

Обычно используется Docker Compose:

```bash
docker compose up -d --build
```
