🚀 Основной функционал
👤 Личный кабинет клиента
Multi-profile: Система "Родитель — Атлеты" (управление несколькими учениками с одного аккаунта).
P2P Оплаты: Покупка абонементов прямыми переводами с административным подтверждением (без сложного эквайринга).
Smart QR-пропуск: Динамический QR-код с криптографической подписью (защита от скриншотов и копирования).
Гибкая заморозка: Самостоятельная приостановка абонемента на 5 дней с автоматическим пересчетом срока.
Умная валидация: Допуск на тренировку с учетом 5-минутного люфта.
🛠 Панель администратора & API
Dashboard: Визуальное управление БД через SQLAdmin (пакетный импорт, экспорт, правка данных).
Analytics: Генерация сложных финансовых отчетов в один клик (Pandas + XlsxWriter).
Security: Защита аналитических эндпоинтов через API Key Header.
Reporting: Ежедневная авто-отчетность в 22:00 и еженедельные бэкапы БД прямо в чат.
💻 Технический стек
Core: Python 3.11+ | Aiogram 3.x (Async) | FastAPI.
Database: PostgreSQL + SQLAlchemy 2.0 (Async ORM).
Migrations: Alembic (автоматическое управление схемой БД).
State Management: Redis (надежный FSM, устойчивый к перезагрузкам).
Infrastructure: Docker & Docker Compose (полная изоляция: Bot, API, DB, Redis).
🏗 Архитектурные особенности
Auto-Migrations: Alembic интегрирован в запуск бота. При деплое таблицы создаются и обновляются автоматически (upgrade head).
Reliability: Настроены Healthchecks. Бот дожидается полной готовности БД перед стартом.
Persistence: Именованные Volumes (pg_data) гарантируют сохранность данных при обновлении контейнеров.

## 🛡 Безопасность и защита данных
*   **Автоматический Backup:** Система еженедельно (по расписанию) создает полный дамп базы данных PostgreSQL и отправляет его в зашифрованном виде в Telegram-чат главного администратора.
    *   *Восстановление:* В случае сбоя оборудования базу можно развернуть из последнего сообщения за 2 минуты.
*   **Изоляция в Docker:** База данных недоступна из внешней сети, к ней имеют доступ только сервисы бота и API внутри закрытой сети Docker.
*   **Подпись QR-кодов:** Каждый пропуск содержит криптографический хэш. Даже если клиент изменит ID в тексте QR-кода, система валидации отклонит его из-за несовпадения подписи.
*   **API Protection:** Доступ к финансовой статистике через FastAPI закрыт кастомным Middleware с проверкой API-ключа (Header Security).
## 🛡 Безопасность и отказоустойчивость
*   **API-Driven Backups:** Система резервного копирования реализована на уровне FastAPI. Еженедельно (или по запросу админа) сервис генерирует полный дамп PostgreSQL и отправляет его в Telegram-чат администратора.
*   **Encapsulated Infrastructure:** База данных и Redis изолированы внутри сети Docker и недоступны извне. Общение происходит только между контейнерами.
*   **Signed QR-Pass:** Каждый пропуск защищен криптографической подписью (HMAC/SHA256). Подделка или ручное изменение ID в QR-коде исключены.
*   **Security Header:** Все аналитические эндпоинты FastAPI защищены API-ключом (X-API-Key), что исключает несанкционированный доступ к финансовым данным через браузер.

Хендлер manual_add_process_name переключает на ввод телефона.

Функция get_profile_keyboard(is_authorized: bool) принимает аргумент.

Итог: Если человек не привязан, он видит кнопку «🔐 Привязать профиль».
4. Процесс авторизации (Самое важное)

Шаг Г: Выполняется student.parent_id = message.from_user.id и session.commit().
Итог: Студент «нашел» своего родителя в Телеграме.
