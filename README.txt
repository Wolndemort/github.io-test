# 🥋 GymManagement CRM Bot
**Умная Self-hosted CRM-система для автоматизации фитнес-клубов, студий и залов единоборств.**
Комплексное решение на базе **Aiogram 3** и **PostgreSQL** для управления абонементами, контроля посещений и глубокой аналитики.
---
## 🚀 Основной функционал
### 👤 Личный кабинет клиента
* **Управление профилями:** Поддержка системы "Родитель — Атлеты" (один аккаунт может управлять несколькими учениками).
* **Покупка абонементов:** Реализована логика оплаты прямыми переводами (P2P) с подтверждением администратором (идеально для работы без сложного эквайринга).
* **Заморозка:** Возможность приостановить абонемент на 5 дней прямо из бота.
* **Статус в реальном времени:** Проверка срока действия и остатка занятий.
* **Smart QR-пропуск:** Динамический QR-код с **криптографической подписью** для защиты от копирования.
* **Допуск на стыке часов:** Умная валидация входа (учитывает 5-минутный люфт к началу тренировки).
### 🛠 Панель администратора
* **Регистрация и поиск:** Быстрый поиск атлета по базе и ручная регистрация (оплата наличными).
* **Рассылки:** Массовое информирование клиентов о новостях и акциях.
* **Автоматическая отчетность:**
    * Ежедневный отчет в **22:00** (статистика визитов и продаж за день).
    * Ручная выгрузка базы в формат **CSV**.
* **Безопасность данных:** Еженедельный автоматический бэкап всей базы данных прямо в чат администратора.

## 💻 Технический стек

Обновленный технический стек
Core: Python 3.11+ | Aiogram 3.x (Asynchronous).
API & Admin: FastAPI + SQLAdmin (Dashboard для управления данными).
Database: PostgreSQL + SQLAlchemy 2.0 (мощный ORM с поддержкой асинхронности).
State Management: Redis (надежное хранение состояний FSM, устойчивое к перезагрузкам).
Analytics: Pandas + XlsxWriter (генерация сложных финансовых отчетов в один клик).
Security:
Криптографическая подпись QR-пропусков.
API Protection: Защита аналитических эндпоинтов через API Key Header (Security Depends).
Infrastructure: Docker & docker-compose (полная изоляция сервисов: Bot, API, DB, Redis).

** запись состояний FSM( REDIS) Перешли с Memory на Redis (теперь FSM надежен).
URL: http://localhost:8000/admin/revenue
Возможности: Визуальное управление БД, пакетный импорт студентов, экспорт финансовой аналитики через Pandas в один клик.
Безопасность: Закрыли статистику API-ключом(Deepends, starlette)
Умная разморозка: автоматический пересчет срока действия абонемента при досрочном выходе с сохранением честного остатка дней»
---добавил dokerignore
Generic single-database configuration with an async dbapi.
Alembic в Bot: Бот сам накатывает миграции перед стартом. Это избавляет от ручного управления схемой БД.
Healthcheck: Сервис bot ждет, пока Postgres (db) будет реально готов (service_healthy), а не просто "запущен".
Единый Стек: И Бот, и FastAPI (gym-api) используют одну и ту же базу данных через DB_FILE.
Персистентность: Данные базы сохраняются в именованный volume pg_data, так что при перезагрузке контейнеров информация об атлетах не пропадет.
