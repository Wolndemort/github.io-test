1. Общие положения

Использование Сервиса, запуск бота с помощью команды /start, а также прохождение авторизации означают безоговорочное согласие Пользователя с настоящей Политикой и указанными в ней условиями обработки его персональных данных.

2. Состав обрабатываемых данных

Оператор обрабатывает следующие категории данных:

  • Профильные данные: Telegram User ID, Username, ФИО атлета, номер телефона, дата рождения.
  • Технические логи: логи проходов через турникет СКУД, видеопоток с камер общего наблюдения на территории зала.
  • Данные СКУД Face ID (Биометрия): Оператор не собирает и не хранит биометрические персональные данные (фотографии, слепки лиц). Терминал доступа мгновенно преобразует изображение в обезличенный математический вектор (хэш-код дескриптора). Обратное восстановление фотографии из этого кода технически невозможно.
  • Данные платежных карт: Оператор не хранит реквизиты банковских карт Пользователей. Все платежи проходят на стороне сертифицированного платежного шлюза. При сохранении карты в боте сохраняется только зашифрованный токен (маска карты) для повторных официальных списаний.

3. Цели обработки данных

Данные обрабатываются исключительно для обеспечения базового функционала Клуба:

  • Идентификация атлета в Telegram-боте и Личном кабинете.
  • Автоматизация и контроль доступа в тренировочные зоны (включая защиту от передачи QR-пропусков третьим лицам).
  • Проведение официальных оплат, фискализация платежей и отправка электронных чеков.

4. Изоляция данных

Платформа реализует концепцию мультиарендности (Multi-tenancy) с программно-аппаратной изоляцией баз данных на уровне уникальных поддоменов клубов. Перекрестный доступ к базам данных разных филиалов или сторонних клубов полностью исключен.

5. Права пользователей и удаление данных

Пользователь вправе в любой момент отозвать согласие на обработку данных или отключить привязанную карту:

  • Управление картой и отписками осуществляется самостоятельно через интерфейс Telegram-бота.
  • Полный отзыв согласия на обработку данных осуществляется путем направления уведомления на Email: Kid.cudi.1995@mail.ru.
  • Отзыв согласия влечет за собой немедленное удаление профиля атлета из базы данных и полную блокировку доступа через систему СКУД.
